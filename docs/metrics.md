# Словарь метрик

Одна метрика - одно определение. Если число на двух дашбордах считается по-разному, это ошибка.

| Метрика | Определение | Формула | Источник | Аддитивна? |
|---|---|---|---|---|
| Показы | Объявление показано в выдаче | `countIf(event_type = 'impression')` | `marts.fct_*` | да |
| Просмотры | Открыта карточка объявления | `countIf(event_type = 'view')` | `marts.fct_*` | да |
| Контакты | Пользователь связался с продавцом (звонок или сообщение) | `countIf(event_type = 'contact')` | `marts.fct_*` | да |
| CTR | Доля показов, после которых открыли карточку | просмотры / показы | считается в запросе | нет - делить суммы, не усреднять доли |
| CR просмотр - контакт | Доля просмотров, закончившихся контактом | контакты / просмотры | считается в запросе | нет |
| DAU платформы | Уникальные пользователи за день | `uniqExact(user_id)` | `marts.fct_platform_daily` | нет - по дням не суммируется |
| Аудитория за период | Уникальные пользователи за период | `uniqHLL12Merge` по `marts.users_daily_agg` | MV | нет; погрешность ~1,6% |
| Выручка продвижения | Сумма оплаченных заказов | `sum(amount) WHERE status = 'paid'` | `finance.promo_orders` | да |
| Возвраты | Сумма заказов в статусе refunded | `sum(amount) WHERE status = 'refunded'` | `finance.fct_promo_revenue_daily` | да |
| Платящие продавцы | Продавцы с хотя бы одним оплаченным заказом за период | `COUNT(DISTINCT seller_id)` | `finance.promo_orders` | нет - пересчитывать за нужный период |
| ARPPU | Выручка на платящего продавца | выручка / платящие продавцы | считается в запросе | нет |
| Удержание M*n* | Доля продавцов когорты, оплативших продвижение снова через *n* месяцев | активные в месяце *n* / размер когорты | `finance.fct_seller_retention` | нет |
| Uplift «до / во время» | Во сколько раз растут контакты у того же объявления во время продвижения | Σ контактов в день во время / Σ контактов в день за 14 дней до (только `is_eligible`) | `marts.promo_order_effect` | нет |
| Наивный uplift | Во сколько раз у продвигаемых объявлений больше контактов, чем у остальных | avg(контакты) продвигаемых дней / avg(контакты) остальных | `marts.fct_listing_daily` | нет; завышен селекционным эффектом |
| Дополнительные контакты | Прирост контактов за время продвижения относительно базы | (контакты в день во время − до) × дней продвижения | `marts.promo_order_effect` | да |
| Стоимость доп. контакта | Сколько рублей продавец платит за один дополнительный контакт | выручка / дополнительные контакты | считается в запросе | нет |

## Правила, которые легко нарушить

* Конверсии считаются как отношение сумм за период, а не как среднее дневных конверсий:
  день с десятью просмотрами не должен весить столько же, сколько день с десятью тысячами.
* Уникальные пользователи и платящие продавцы не суммируются по дням и категориям.
  В витринах они либо отсутствуют, либо помечены в описании колонки.
* Даты - UTC. Граница суток в событиях одна для всех систем.
* Выручка считается по дате создания заказа, активность - по дате события.
